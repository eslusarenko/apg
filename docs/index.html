Strong passwords,
straight from the terminal

apg is the classic Linux password generator, reimplemented for macOS, Linux and Windows. Same options, sensible defaults, and a few things that make everyday use simpler.

brew install eslusarenko/tap/apg

or go install github.com/eslusarenko/apg@latest, or grab a binary

What it does

Strong by default

Plain apg prints a 32-character password of letters, digits and symbols. No options to remember.

Pronounceable passwords

The FIPS-181 algorithm from the original apg: apg -a 0 -t gives words like RytJugHus you can read aloud.

PIN codes

apg --pin --length 6 for a six-digit code, --alnum when a site rejects symbols.

Straight to the clipboard

--copy uses pbcopy, clip, wl-copy or xclip. -d drops the trailing newline for pipes.

Your defaults

Set default_length and default_strategy once in ~/.apg.conf.

Cryptographically random

Every character comes straight from the system's cryptographic random generator, chosen uniformly.

Familiar if you used apg on Linux

The options of the classic apg by Adel I. Mirzazhanov keep their meaning: -a, -M, -E, -n, -m, -x, -r, -t, -l and the rest. Your scripts and muscle memory keep working.

  • The defaults are stronger: one random 32-character password instead of six short pronounceable ones.
  • Bloom filter, crypt(3) and cracklib options are not supported, and apg says so instead of silently skipping a check.
  • man apg and shell completions for bash, zsh and fish come with the Homebrew package.
# the classic apg defaults
$ apg -a 0 -n 4 -m 8 -x 10 -M sncl
TedceOf~
liavAndead
vobbyQuir
nadUcWouv

# no look-alike characters
$ apg -E 'O0Il1|' --length 16
2#S._4$,SzGv2^tp

# spelled out for reading over the phone
$ apg -m 8 -x 8 -l
A4c[up6d Alfa-FOUR-charlie-LEFT_BRACKET-uniform-papa-SIX-delta
