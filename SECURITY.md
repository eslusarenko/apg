# Security policy

apg generates passwords, so security bugs matter more than any other kind.
Examples: predictable or biased output, characters outside the requested
classes, passwords leaking somewhere they should not.

## Reporting a vulnerability

Please report privately through
[GitHub security advisories](https://github.com/eslusarenko/apg/security/advisories/new)
rather than in a public issue. You will get a reply within a few days.

## Supported versions

Fixes go into the latest release.
